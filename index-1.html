Legislative & Policy Dataset Querying (SQL)

Built a relational schema from public legislative records to cross-reference bill sponsorship, committee votes, and topic tags — used to source evidence for debate briefs above.

query.sql 
SELECT
    b.bill_id,
    b.title,
    b.topic_tag,
    COUNT(v.vote_id) AS total_votes,
    SUM(CASE WHEN v.position = 'yea' THEN 1 ELSE 0 END) AS yea_votes
FROM bills b
JOIN votes v ON b.bill_id = v.bill_id
JOIN legislators l ON v.legislator_id = l.legislator_id
WHERE b.topic_tag IN ('ai_governance', 'data_privacy')
  AND b.session_year >= 2022
GROUP BY b.bill_id, b.title, b.topic_tag
ORDER BY total_votes DESC;

-- Returns AI/privacy bills ranked by legislative engagement,
-- used to prioritize which motions to research next.

Automated Debate Brief Scraping (Python)

A scheduled scraper that pulls newly published motions from tournament announcement pages, tags them by topic using keyword matching, and logs them to a personal research backlog.

scraper.py 
import requests
from bs4 import BeautifulSoup

def fetch_motions(url: str) -> list[dict]:
    """Scrape newly posted tournament motions and topic-tag them."""
    response = requests.get(url, timeout=10)
    soup = BeautifulSoup(response.text, "html.parser")
    motions = []

    for row in soup.select(".motion-row"):
        title = row.select_one(".motion-title").get_text(strip=True)
        motions.append({
            "title": title,
            "tag": classify_topic(title),
            "source": url,
        })
    return motions
